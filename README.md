# Sales & Revenue Dashboard

An interactive dashboard for analyzing sales and revenue data.

## Features
- Import data from Excel (.xlsx) or CSV
- KPIs: total revenue, units sold, average price, month-over-month change
- Charts: revenue trend, revenue by region, top products
- Filters by year, region, category, and product
- Auto-generated business insights

## How to use
Open the live demo, or import your own file with the columns:
Date, Region, Category, Product, Units, Revenue.

Built with HTML, JavaScript, Chart.js, and SheetJS.
